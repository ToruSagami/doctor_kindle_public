# Kindle出版プロジェクト 私家版日本語表記ガイドライン

版：1.0  
制定日：2026年8月12日

## 1．目的

本ガイドラインは、Kindle書籍の文章について、読みやすさ、一貫性、正確さ、著者らしさを両立させるための私家版基準である。

表記の統一そのものを目的にはしない。読者が意味を迷わず受け取れることを最優先とする。自動校正は補助として利用し、文脈を踏まえた最終判断は著者が行う。

## 2．適用範囲

本ガイドラインは、次の文章に適用する。

* 書籍本文
* はじめに、おわりに
* 章見出し、節見出し
* 図表の見出し、注記、脚注
* 奥付、付録
* 商品紹介文など、書籍から派生する文章

コード、コマンド、ファイル名、URL、正式な製品名、引用文には、必要に応じて原表記を用いる。

## 3．判断の優先順位

表記に迷った場合は、次の順で判断する。

1. 意味が正確に伝わるか
2. 読者が一度で理解できるか
3. 同じ意味と用法で表記が統一されているか
4. 著者の語り口が保たれているか
5. 一般的な用字用語の基準に沿っているか

医学用語、法令名、制度名、製品名、団体名などは、読みやすさより正式表記を優先する。ただし、一般読者に理解しにくい専門用語には、初出時に短い説明を添える。

## 4．文体

### 4.1 文末

一つの章では、ですます調またはである調のどちらかに統一する。引用、会話、箇条書き、図表内では例外を認める。

文末表現が単調に続く場合は、語順や文の長さを調整する。ただし、変化をつけるためだけに文体を混在させない。

### 4.2 一文の長さ

一文には、原則として一つの中心内容を置く。主語と述語が離れすぎる場合、修飾関係が曖昧な場合、読点が三つ以上必要になる場合は、文を分けることを検討する。

短文を機械的に連続させない。文章のテンポは保ちつつ、因果関係や対比が伝わるように接続する。

### 4.3 段落

一つの段落では、一つの論点を扱う。段落の冒頭で、その段落が何を述べるのかをできるだけ明らかにする。

段落間は空行で区切る。意味のまとまりが変わらない箇所で、見た目だけを理由に改段落しない。

### 4.4 論証の進め方

結論へ向けて論証を一方向に進める。前の論点へ何度も戻らない。反論や例外を扱う場合は、対象となる考えを正確に示し、理由を述べた後で結論を一度だけ置く。

推量、可能性、仮定は、根拠なく断定へ変えない。

## 5．漢字を閉じるか、ひらがなに開くか

### 5.1 基本原則

意味を担う実質的な語は漢字を基本とする。文法的な働きが中心の語、形式名詞、補助動詞、接続詞、副詞は、読みやすさを損なわない範囲でひらがなに開く。

常用漢字であっても、漢字が続いて読みにくい場合は開くことを検討する。反対に、ひらがなが続いて語の境界が分かりにくい場合は、漢字へ戻すことを認める。

### 5.2 原則として開く語

| 種類 | 基本表記 | 使用例 |
| --- | --- | --- |
| 形式名詞 | こと | 大切なこと |
| 形式名詞 | とき | 判断するとき |
| 形式名詞 | ところ | 確認したところ |
| 形式名詞 | もの | 必要なもの |
| 形式名詞 | わけ | 誤りというわけではない |
| 形式名詞 | うえ | 実行するうえで |
| 形式名詞 | ため | 理解するため |
| 形式名詞 | ほう | 選ばないほうがよい |
| 補助動詞 | できる | 判断できる |
| 補助動詞 | みる | 試してみる |
| 補助動詞 | いく | 考えていく |
| 補助動詞 | くる | 変わってくる |
| 補助動詞 | おく | 確認しておく |
| 補助動詞 | いただく | 読んでいただく |
| 補助動詞 | ください | 確認してください |
| 補助動詞 | ほしい | 知ってほしい |
| 副詞 | たとえば | たとえば、次の方法がある |
| 副詞 | すでに | すでに確認した |
| 副詞 | あらかじめ | あらかじめ決める |
| 副詞 | ほとんど | ほとんど変わらない |
| 接続詞 | さらに | さらに検討する |
| 接続詞 | ただし | ただし、例外がある |
| 接続詞 | したがって | したがって、結論は変わらない |

### 5.3 意味によって書き分ける語

同じ読みでも、実質的な意味を持つ場合は漢字を用いる。

| 開く表記 | 漢字表記 | 判断基準 |
| --- | --- | --- |
| 実行するうえで | 机の上 | 条件や観点か、物理的位置か |
| 判断するとき | 時が過ぎる | 場面を示す形式名詞か、時間そのものか |
| 試してみる | 景色を見る | 補助動詞か、視覚による行為か |
| 考えていく | 病院へ行く | 変化や継続か、移動か |
| 準備しておく | 本を置く | 事前の処置か、物を配置する行為か |
| 理解することができる | 作業が出来上がる | 可能を示す補助表現か、完成を示す語か |

### 5.4 ひらがなが連続する場合

ひらがなが続き、語の境界、文節、修飾関係が分かりにくくなる場合は、次の順で修正を検討する。

1. 語順を変える
2. 分かりやすい表現へ言い換える
3. 文を分ける
4. 意味の区切りが明確になる場合に限り、読点を入れる
5. 言い換えで意味や語り口が損なわれる場合は、常用漢字の範囲で漢字表記へ戻す

読点は、ひらがなの連続を見た目だけで分ける記号ではない。意味のまとまりや修飾関係を明確にできる場合に用いる。

修正前：読者にわかりやすくするために必要な情報を整理する。  
修正案：必要な情報を整理し、読者に伝わりやすくする。

修正前：確認しておいていただくことが必要です。  
修正案：事前の確認が必要です。

### 5.5 漢字の連続

漢字が四字以上連続し、意味のまとまりを取りにくい場合は、助詞を補う、語を開く、説明を加える、文を分ける、のいずれかを検討する。

ただし、固有名詞、法令名、医学用語、定着した複合語は、見た目だけを理由に分解しない。

## 6．推奨する基本表記

同じ意味と用法では、原則として次の表記を用いる。

| 基本表記 | 原則として避ける表記 | 備考 |
| --- | --- | --- |
| できる | 出来る | 完成の意味を除く |
| わかる | 分かる、判る、解る | 専門的な区別が必要な場合を除く |
| 行う | おこなう | 動作として用いる |
| さらに | 更に | 接続詞、副詞 |
| すでに | 既に | 副詞 |
| たとえば | 例えば | 副詞 |
| さまざま | 様々 | 一般向け本文 |
| それぞれ | 各々 | 一般向け本文 |
| もっとも | 最も | 接続詞の場合 |
| 最も | もっとも | 程度が最大の場合 |
| および | 及び | 法令の引用を除く |
| または | 又は | 法令の引用を除く |
| ならびに | 並びに | 法令の引用を除く |
| かかわる | 関わる、係わる | 固有の表記を除く |
| かかわらず | 拘らず | 接続表現 |
| とおり | 通り | 方法や内容を示す場合 |
| 次のとおり | 次の通り | 内容や方法を示す場合。道路や通行の意味では漢字 |
| おわりに | 終わりに | 書籍の章名 |

一覧は絶対規則ではない。文脈によって意味が異なる場合は、意味を優先する。

## 7．句読点

### 7.1 句点

通常の文末には句点を付ける。見出し、表の短い項目、独立した図表タイトルには原則として付けない。

箇条書きでは、各項目が文なら句点を付け、名詞句なら付けない。同じ一覧の中で形式をそろえる。

### 7.2 読点

読点は、次の場合に用いる。

* 主語が長く、述語との関係を明確にする場合
* 条件、理由、対比、転換の区切りを示す場合
* 修飾先の誤読を防ぐ場合
* 並列する要素の境界を示す場合
* 接続詞の後で、自然な区切りが必要な場合

息継ぎの感覚だけで読点を置かない。短い主語の直後、述語の直前、意味が連続する語の間には、原則として置かない。

読点が多い文は、読点を削る前に、語順の変更または文の分割を検討する。

## 8．記号

### 8.1 括弧

日本語本文では全角括弧を用いる。

例：KDP（Kindle Direct Publishing）  
例：Markdown（.md）

括弧内に説明を重ねない。補足が長くなる場合は、本文へ移すか脚注にする。

### 8.2 かぎ括弧

語句の強調、用語の提示、発言、短い引用には「」を用いる。

「」の中でさらに括弧が必要な場合は『』を用いる。強調だけを目的として多用しない。

### 8.3 コロン

日本語本文で用語を定義する場合は、全角コロンを用いる。

例：公衆衛生学：みんなの健康を考える学問

時刻、URL、コード、書式指定では原表記を維持する。

### 8.4 中黒

日本語の語や概念を単に並列する目的では、中黒を多用しない。助詞、読点、接続詞を用いて関係を明らかにする。

固有名詞、一般に定着した複合名称、書誌情報では必要に応じて用いる。

### 8.5 ダッシュ類

日本語の地の文と見出しでは、ダッシュ類を用いない。間、転換、挿入を表したい場合は、句読点、括弧、改行、言い換えを用いる。

コード、コマンド、ファイル名、URL、正式名称では原表記を維持する。

### 8.6 感嘆符と疑問符

疑問文には疑問符を使用できる。感嘆符は、著者の語り口として必要な場合に限り、連続使用を避ける。

記号の直後に文章が続く場合は、電子書籍での表示崩れを避けるため、組版結果を確認する。

### 8.7 省略記号

省略や余韻は、原則として文章で表す。三点リーダーの多用は避ける。会話などで必要な場合は、書籍内で個数と表記を統一する。

## 9．数字と単位

### 9.1 数字

## 9.4 数字の表記

数量、年齢、日付、時刻、割合、ページ番号は算用数字を基本とする。算用数字は、原則として半角で表記する。一桁の数字も全角にしない。

例：3人、50歳、2026年8月12日、10％、第3章

熟語、慣用表現、概数、固有名詞では、必要に応じて漢数字を用いる。

例：一人ひとり、一度に、数十年、第一歩、千差万別
例：数万円
例：乃木坂46、三井住友銀行、四谷三丁目

文脈によって数量か熟語かが異なる語は、意味に応じて書き分ける。

### 9.2 桁区切り

四桁以上の数値には、必要に応じて半角カンマを用いる。年号には用いない。

例：12,000円  
例：2026年

桁区切りのカンマと小数点は半角とし、数字と単位の間には空白を入れない。

### 9.3 単位

単位の表記は、分野の慣例と国際的な表記を尊重する。同一書籍内では、数字と単位の間隔、全角と半角、大文字と小文字を統一する。

医学的数値は、単位の欠落が意味を変えるため、数値と単位を必ず対で確認する。

### 9.4 縦書き

縦書きでの表示は全角数字によって調整せず、EPUB生成後に縦中横や改行位置を確認する。

## 10．英字、外来語、略語

英数字は半角を基本とする。英文、コード、コマンド、ファイル名では原表記を維持する。

略語は、一般読者が理解できない可能性がある場合、初出時に正式名称または短い説明を添える。

例：KDP（Kindle Direct Publishing）

製品名、サービス名、団体名は公式表記を優先する。表記が更新される可能性があるものは、基準日時点の公式情報を確認する。

外来語の長音、分かち書き、大文字と小文字は、一冊の中で統一する。

## 11．専門用語

専門用語は、正確さを保ったまま、一般読者が意味を調べずに読める表現へ言い換える。完全な言い換えが難しい場合は、初出時に短く説明する。

機序、病態、予後、適応、所見などは、読者像に応じて説明または言い換えを検討する。

ただし、医学的意味、法的意味、制度上の定義を変えてはならない。意味を保てるか判断できない場合は、無理に言い換えず、要確認事項として残す。

病名、薬剤名、検査名、法令名、制度名は正式表記を優先する。通称を用いる場合は、正式名称との関係が分かるようにする。

## 12．引用と出典

引用文は、原文の表記を尊重する。現在の表記基準に合わせるために、引用文を無断で改めない。

引用の誤字と思われる箇所、旧字体、歴史的仮名遣いを修正する必要がある場合は、引用の正確性を損なわない方法を選ぶ。

本文中の数値、日付、固有名詞、制度、医学的主張は、基準日時点の出典と照合する。出典が主張の一部しか支えない場合は、本文の断定範囲を狭める。

## 13．見出し

見出しは、一つの自然な句として作る。複数の論点を記号で連結しない。

見出しだけで内容をおおむね予測できるようにする。抽象的な名詞だけの見出し、内容を誇張する見出し、本文に答えがない疑問形は避ける。

見出し階層は、Markdownの見出し記号で管理する。本文中で見出しらしさを出すためだけに、太字や記号を乱用しない。

章名と節名では、同じ階層の文法形式をできるだけそろえる。

## 14．箇条書きと表

箇条書きは、並列関係が明確な場合に用いる。説明が連続する内容は文章にする。

各項目は、名詞句または文のどちらかにそろえる。一つの項目へ複数の論点を詰め込まない。

表は、複数の対象を同じ観点で比較する場合に用いる。長文を表へ押し込まない。電子書籍では画面幅が狭いため、列数を増やしすぎない。

## 15．著者の語り口

著者の経験、判断、温度感、ユーモアは残す。校正によって、無個性な説明文へ変えない。

入力資料にない経験、発言、感情、実績、失敗談は創作しない。事実が不足している場合は、もっともらしく補わず、著者への確認事項として分離する。

皮肉やユーモアは、読者や特定の属性を傷つけるために用いない。内容の理解を助け、文章の緊張を和らげる範囲にとどめる。

恐怖、不安、劣等感を過度に刺激して行動を促さない。効果、利益、安全性を根拠なく保証しない。

## 16．避ける表現

次の表現は、根拠と文脈を確認し、安易に用いない。

* 必ず
* 絶対
* 誰でも
* 確実に
* 最短
* 簡単に
* 完全に
* 劇的に
* 唯一の

抽象的で意味が広すぎる語は、具体的な内容へ言い換える。とくに、仕組み、構造、本質、最適化、アップデートなどは、何を指すかを明らかにする。

## 17．自動校正の運用

### 17.1 自動修正してよい項目

次の項目は、文脈に影響しないことを確認したうえで、自動修正できる。

* 全角括弧と半角括弧の統一
* 明らかな空白の重複
* 同一用法における表記ゆれ
* 見出し階層の形式的な不一致
* 数字、単位、英字の明らかな表記不一致

### 17.2 自動修正しない項目

次の項目は、一括置換せず、文脈ごとに判断する。

* うえと上
* ときと時
* みると見る
* いくと行く
* おくと置く
* ものと物
* ことと事
* もっともと最も
* とおりと通り
* できると出来る

### 17.3 校正結果の示し方

校正では、修正後の原稿だけでなく、判断が必要な箇所を要確認事項として分ける。

意味が変わる可能性がある修正、著者の経験に関する修正、専門的妥当性を判断できない修正は、勝手に確定しない。

## 18．校正時の確認順序

1. 事実関係と出典
2. 中心命題と論理の流れ
3. 段落と文の役割
4. 文体と語り口
5. 漢字の開閉
6. 語句と表記の統一
7. 句読点と記号
8. 数字、単位、固有名詞
9. Markdownと電子書籍上の表示

表記だけを先に整えると、後の改稿で修正が無駄になりやすい。内容を確定してから細部を整える。

## 19．最終チェックリスト

* 同じ意味と用法の語が同じ表記になっているか
* 開いた語が連続し、語の境界が分かりにくくなっていないか
* 読点が見た目だけの区切りになっていないか
* 語順変更や文の分割で、より明確にできないか
* 漢字が続き、意味のまとまりが見えにくくなっていないか
* 主語と述語、修飾語と修飾先が対応しているか
* ですます調とである調が不用意に混在していないか
* 専門用語が一般読者にも理解できるか
* 医学的意味や制度上の定義を変えていないか
* 数値、単位、日付、固有名詞を確認したか
* 引用と出典が本文の主張を直接支えているか
* 著者の経験や発言を創作していないか
* 著者らしい語り口が不必要に消えていないか
* 見出しが一つの自然な句になっているか
* Kindle端末とスマートフォンで表示を確認したか

## 20．個別用字用語表の運用

本ガイドラインとは別に、書籍ごとの用字用語表を作成する。その書籍固有の表記は、本ガイドラインより優先する。

用字用語表には、少なくとも次を記録する。

| 項目 | 記録内容 |
| --- | --- |
| 採用表記 | 本文で使う表記 |
| 不採用表記 | 原則として使わない表記 |
| 適用条件 | 意味や用法による例外 |
| 初出箇所 | 最初に説明する章や節 |
| 根拠 | 公式表記、辞典、著者判断など |
| 備考 | 読者像や文体上の注意 |

新しい判断が生じた場合は、原稿だけを直して終わらせず、用字用語表へ追記する。一冊の中で判断を再利用できる状態にする。
