# Kindle本の文体と表記の最終点検プロンプト

事実確認済み原稿、著者文体サンプル、用字用語表、私家版Kindle表記ガイドラインを用い、入稿用原稿へ整えてください。

## 入力

1. 事実確認済み原稿
2. 著者文体サンプル
3. 書籍固有の用字用語表
4. 私家版Kindle表記ガイドライン

## 目的

著者の語り口を残しながら、誤字脱字、文体の混在、不自然な反復、曖昧な表現、表記不一致を整理します。内容、論理、事実を変えません。

## 判断順位

1. 事実の正確さと専門的意味
2. 著者が明示した意図
3. 書籍固有の用字用語表
4. 私家版Kindle表記ガイドライン
5. 著者文体サンプル
6. 一般的な日本語表記

## 点検手順

点検結果の作成前に、次の候補を原稿全体から全件抽出する。

1. スタイルガイドの採用表記と不採用表記
2. 4桁以上の数値
3. 割合、単位、年号、経過年数
4. 読点を含むすべての文
5. 地域名と複合語の語順違い
6. 同じ固有名詞の空白、漢字、英字の違い
7. 略語と専門用語の初出箇所
8. 章名、節名、本文で異なる表記
9. はじめに、おわりに、奥付の媒体名と著者名
10. スタイルガイドで避けるとした表現

候補を抽出し終えるまで、点検概要と修正一覧を作成しない。

## 点検項目

1. 誤字、脱字、助詞、主語と述語、修飾関係
2. ですます調とである調の混在
3. 同じ文末、接続詞、指示語、抽象語の不自然な連続
4. 一文への論点の詰め込みと短文の過剰な連続
5. 同義反復、結論の繰り返し、説明文調
6. 専門用語の初出説明と正式表記
7. 漢字の開閉、送り仮名、仮名遣い
8. 数字、英字、単位、記号、括弧、空白、改行
9. 固有名詞、法令名、制度名、引用、コード、URL
10. 見出しと箇条書きの形式

## 数字の全件点検

4桁以上の数字をすべて抽出し、次のいずれかに分類する。

| 分類           | 表記例       |
| -------------- | ------------ |
| 年号           | 2026年       |
| 経過年数       | 約9,000年前  |
| 数量           | 12,000円     |
| 日本語の位取り | 2万4,665円   |
| 識別番号       | 原表記を維持 |
| 固有名詞       | 原表記を維持 |

分類できない数字は要確認とする。
同じ原稿内の4桁以上の数字について、未判定件数が0件になるまで完了としない。

## 表記規則

1. 算用数字と英数字は原則として半角にする
2. 数字と単位の間は原則として空けない
3. 形式名詞と補助動詞は原則として開く
4. 実質的な意味を持つ漢字は機械的に開かない
5. ひらがなが続いて読みにくい場合は、語順変更、言い換え、文の分割、意味を明確にする読点、漢字へ戻す、の順で検討する
6. 文法上不要な読点を見た目だけの理由で加えない
7. 固有名詞、引用、コード、コマンド、ファイル名、URLは原表記を優先する
8. 意味の異なる語を一括置換しない

## 読点の全件点検

読点を含む文をすべて抽出し、読点ごとに次を判定する。

1. 主語と述語の関係を明確にしている
2. 条件、理由、対比、転換を示している
3. 修飾先の誤読を防いでいる
4. 並列要素の境界を示している
5. 接続詞の後の自然な区切りである
6. 文法上不要である

短い主題の直後、助詞の直後、意味が連続する語の間にある読点を重点的に確認する。
不要な読点を削るだけで修飾関係が曖昧になる場合は、語順変更または文の書き換えを提案する。

## 頻出語の判定

頻出語を、維持、調整候補、要確認、表記統一に分類してください。回数だけで削除せず、出現間隔、密度、役割、読者理解への影響を見てください。

## 修正規則

1. 原文を生かし、必要な箇所だけを直す
2. 推量を断定へ変えない
3. 事実、数値、専門的意味を変えない
4. ユーモア、皮肉、自虐を機械的に削らない
5. 著者の経験、発言、感情、実績を作らない
6. 内容変更が必要な問題は修正せず、戻り先を示す
7. 地域名や複合語について、語順を入れ替えた表現も抽出する。例として北部九州と九州北部、日本北部と北日本などを確認し、意味が同じ場合は統一し、専門分野で使い分けがある場合は要確認とする

文体の特徴、適用規則、重大な問題の有無を示してください。

### 5. 用字用語表の更新案

今回新たに決めた事項だけを示してください。

### 6. 修正反映

著者が「修正を反映」と入力した場合、確定可能な修正を一ファイルずつ全文へ反映してください。内容を変える修正は行わないでください。

### 7. 要確認事項と完成状況

著者判断が必要な事項、戻る工程、未解決件数を示してください。

## 完了条件

1. 著者らしさと読みやすさを保っている
2. 同じ意味と用法の表記が統一されている
3. 頻出語を回数だけで処理していない
4. 事実と専門的意味を変えていない
5. 入稿用原稿と用字用語表を確定できる
