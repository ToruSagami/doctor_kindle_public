# Kindle本の「はじめに」と「おわりに」最終調整プロンプト

全章修正後の原稿を基に、「はじめに」の約束が本文で果たされ、「おわりに」で回収されるように整えてください。「おわりに」がない場合は新規作成してください。

## 入力

1. 全章横断点検後の原稿
2. 承認済み出版企画書と中心命題
3. 既存の「はじめに」と読者への約束一覧
4. 既存の「おわりに」
5. 文体規則、表記規則

## 目的

対象読者、課題、読む理由、得られる成果、扱う範囲を本文と一致させ、入口と出口の齟齬をなくします。

## 点検項目

### 「はじめに」

1. 想定読者と読む理由が明確か
2. 中心命題への入口があるか
3. 約束が本文の範囲内か
4. 著者の立場と経験が確認済みか
5. 目次紹介や結論の先取りに偏っていないか

### 「おわりに」

1. 中心命題が本文を踏まえて示されるか
2. 主要な約束を過不足なく回収するか
3. 本文にない主張、成果、事例、根拠を加えていないか
4. 各章の機械的な再要約になっていないか
5. 読者が得た判断基準と次の一歩を確認できるか

## 修正規則

1. 維持、表現調整、約束縮小、回収追加、重複削減、順序調整、本文確認、要確認に分類する
2. 未達の約束は本文を水増しする前に適正な範囲へ縮小する
3. 「おわりに」で新しい論証を始めない
4. 入口と出口だけで解決できない問題は全章横断点検工程へ戻す
5. 入力にない経験、感情、実績を作らない
6. 文体規則と表記規則を保つ

## 出力

### 1. 約束と回収の対応表

| 種類 | 「はじめに」の約束 | 本文の履行箇所 | 「おわりに」の回収 | 判定 | 対応 |
|---|---|---|---|---|---|

判定は、回収済み、一部回収、未回収、過大、回収不要のいずれかとしてください。

### 2. 確定した「はじめに」

先頭見出しを「# はじめに」とし、全文をMarkdown形式で示してください。

### 3. 確定した「おわりに」

先頭見出しを「# おわりに」とし、全文をMarkdown形式で示してください。章番号は付けないでください。

### 4. 要確認事項

企画書との不一致、未達の約束、著者の意図など、本人判断が必要な事項だけを示してください。

### 5. 完成状況

未回収、過大な約束、本文との不一致、要確認事項の件数を示してください。

## 完了条件

1. 主要な約束が本文で果たされている
2. 「おわりに」で主要な成果を回収している
3. 本文にない主張や成果を追加していない
4. 行動提案が本文と読者像に合う
5. 「はじめに」と「おわりに」が完成原稿として使える
